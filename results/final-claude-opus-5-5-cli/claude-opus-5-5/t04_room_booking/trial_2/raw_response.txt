The approach: lock the room's row before checking for overlaps, so requests for the same room take turns.

- **Overlaps cannot happen.** Each request starts a read-committed transaction and takes `SELECT ... FOR UPDATE` on the room's row. Requests for the same room then run one at a time. Each one does its overlap check and insert while holding the lock. Because read committed takes a fresh snapshot for each statement, the overlap check sees any booking committed by the previous lock holder.
- **Bookings that fit still succeed.** A request that arrives while another holds the lock waits; it is not refused. After waiting, it sees the committed state. That is the same state it would see if the requests ran one after another, so non-overlapping requests all return `True`.
- **No deadlocks from this code.** Each transaction takes exactly one row lock, so two requests cannot each hold a lock the other needs. A bounded retry loop catches any transient serialization or deadlock error anyway.
- **Overlap test.** It uses half-open intervals: `existing.starts_at < new.ends_at AND existing.ends_at > new.starts_at`. So back-to-back bookings like 10:00–11:00 and 11:00–12:00 are allowed.
- **No exclusion constraint.** `migrate` only adds an index for speed. An exclusion constraint could fail to create if the existing data already contains overlaps, and the room lock already guarantees correctness.

```python
import psycopg.errors as errors


def migrate(db) -> None:
    db.execute(
        "CREATE INDEX IF NOT EXISTS bookings_room_time_idx "
        "ON bookings (room_id, starts_at, ends_at)"
    )


_RETRYABLE = (
    errors.SerializationFailure,
    errors.DeadlockDetected,
    errors.LockNotAvailable,
)


def book_room(db, room_id, starts_at, ends_at) -> bool:
    last_exc = None
    for _ in range(8):
        try:
            db.begin("read committed")
            # Serialize all bookings for this room.
            db.execute(
                "SELECT id FROM rooms WHERE id = %(room)s FOR UPDATE",
                {"room": room_id},
            )
            conflict = db.execute(
                "SELECT 1 FROM bookings "
                "WHERE room_id = %(room)s "
                "AND starts_at < %(e)s AND ends_at > %(s)s "
                "LIMIT 1",
                {"room": room_id, "s": starts_at, "e": ends_at},
            )
            if conflict:
                db.rollback()
                return False
            db.execute(
                "INSERT INTO bookings (room_id, starts_at, ends_at) "
                "VALUES (%(room)s, %(s)s, %(e)s)",
                {"room": room_id, "s": starts_at, "e": ends_at},
            )
            db.commit()
            return True
        except _RETRYABLE as exc:
            last_exc = exc
            try:
                db.rollback()
            except Exception:
                pass
            continue
        except Exception:
            try:
                db.rollback()
            except Exception:
                pass
            raise
    raise last_exc
```
