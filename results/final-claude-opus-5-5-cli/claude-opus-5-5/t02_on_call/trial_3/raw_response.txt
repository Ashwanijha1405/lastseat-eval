The problem here is a write skew. If each request checks "is someone else on call?" and then goes off call, two doctors can both see the other as on call and both leave, so the shift ends up with nobody. The fix is to lock the shift's row first. That makes all requests for the same shift run one at a time, in a queue. Each one checks and updates only after the previous request has committed.

- **Rule 1 (at least one doctor on call):** in read committed, every statement takes a fresh snapshot. So once a request holds the shift lock, its count includes all earlier requests that already went off call. Two requests can never both act on stale data.
- **Rule 2 (valid requests succeed):** a competing request waits for the lock instead of failing. When it gets the lock it sees the true current state. A request that would succeed if run alone therefore still succeeds.
- **Deadlocks:** each transaction takes only one lock, so they can't occur. A small, bounded retry loop still covers any unexpected transient error.
- **Lock type:** `FOR NO KEY UPDATE` is enough to make same-shift requests queue. It is lighter than `FOR UPDATE` and does not block foreign-key checks.

```python
import psycopg.errors as errors

_RETRYABLE = (
    errors.SerializationFailure,
    errors.DeadlockDetected,
    errors.LockNotAvailable,
)


def migrate(db) -> None:
    db.execute(
        "CREATE INDEX IF NOT EXISTS doctors_shift_on_call_idx "
        "ON doctors (shift_id) WHERE on_call"
    )


def go_off_call(db, doctor_id: int) -> bool:
    last_exc = None
    for _ in range(8):
        try:
            db.begin("read committed")
            # Serialize all requests for the same shift by locking the shift row.
            rows = db.execute(
                "SELECT s.id FROM shifts s "
                "JOIN doctors d ON d.shift_id = s.id "
                "WHERE d.id = %s "
                "FOR NO KEY UPDATE OF s",
                (doctor_id,),
            )
            if not rows:
                db.rollback()
                return False
            shift_id = rows[0][0]

            # Fresh snapshot (read committed): sees all previously committed changes.
            others = db.execute(
                "SELECT 1 FROM doctors "
                "WHERE shift_id = %s AND on_call AND id <> %s "
                "LIMIT 1",
                (shift_id, doctor_id),
            )
            if not others:
                db.rollback()
                return False

            db.execute(
                "UPDATE doctors SET on_call = false WHERE id = %s",
                (doctor_id,),
            )
            db.commit()
            return True
        except _RETRYABLE as exc:
            last_exc = exc
            try:
                db.rollback()
            except Exception:
                pass
            continue
    raise last_exc
```
